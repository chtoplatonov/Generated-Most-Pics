# Generated-Most-Pics

Проект формирует готовую карточку с текущей обстановкой на Крымском мосту. Карточка подходит для публикации в Telegram и включает дату, время, погоду и баллы загруженности «В Крым» и «На Кубань».

Этот README написан для пользователя, который впервые сталкивается с Python‑проектами. Следуйте инструкциям шаг за шагом — и у вас появится готовый инструмент.

---

## Что делает проект

1. **Получает сообщение** из Telegram-канала с информацией о мосте.
2. **Извлекает время и текст** по каждому направлению.
3. **Подгружает данные**: актуальную погоду и баллы пробок из Яндекс.Карт.
4. **Собирает карточку-изображение**, оформленную по заданному шаблону.
5. **(Опционально) Публикует** результат обратно в Telegram через бота.

## Как установить проект (пошагово)

1. **Скачайте код**. Откройте терминал и выполните:
   ```bash
   git clone https://github.com/your-account/Generated-Most-Pics.git
   cd Generated-Most-Pics
   ```
   > Если Git не установлен, скачайте архив проекта и распакуйте его вручную.

2. **Создайте виртуальное окружение** (изолированная папка с библиотеками):
   ```bash
   python -m venv .venv
   ```

3. **Активируйте окружение**:
   - Windows (PowerShell):
     ```powershell
     .venv\Scripts\Activate.ps1
     ```
   - macOS / Linux:
     ```bash
     source .venv/bin/activate
     ```

4. **Установите зависимости**:
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

5. **Подготовьте данные для настройки**. Они понадобятся позже:
   - `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` — в личном кабинете [my.telegram.org](https://my.telegram.org/auth).
   - `TELEGRAM_BOT_TOKEN` — создайте бота через @BotFather и запишите токен.
   - `TELEGRAM_SOURCE_CHAT` — ссылка или ID канала, откуда берёте сообщения.
   - `TELEGRAM_DESTINATION_CHAT` — куда отправлять карточки (можно тот же канал).
   - `YANDEX_TRAFFIC_API_KEY` — ключ от Яндекс.Карт Traffic API.
   - (Опционально) `CARD_BACKGROUND` — путь к вашему изображению фона.

## Помощник по настройке (HTML-страница)

Чтобы не хранить ключи в разбросанных файлах, мы подготовили простую визуальную форму: [`assets/setup_helper.html`](assets/setup_helper.html).

1. Откройте файл двойным кликом или через контекстное меню «Открыть с помощью» → браузер.
2. Введите значения всех полей.
3. Нажмите **«Сгенерировать команды»** — страница подскажет, какие переменные окружения нужно задать и как создать файл `.env`.
4. Скопируйте команды в терминал или сохраните содержимое готового файла.

Файл работает полностью офлайн и не отправляет данные в интернет.

## Как сгенерировать карточку вручную

Если нужно создать одну карточку из текста (без бота):

```bash
export YANDEX_TRAFFIC_API_KEY="ваш_ключ"
echo "09:00

Со стороны Тамани очереди перед пунктом ручного досмотра нет." | \
  python -m src.generate_card -o output/card.png
```

Пояснения:

- Скрипт автоматически загрузит погоду и баллы загруженности.
- Файл сохранится по пути, указанному после `-o` (папка `output` создаётся заранее).
- Если нужно изменить фон, добавьте параметр `--background path/to/image.jpg`.

## Как запустить Telegram-бота

1. **Запишите ключи в переменные окружения.** Проще всего использовать вывод из `setup_helper.html`. Для Linux/macOS пример:
   ```bash
   export TELEGRAM_API_ID=123456
   export TELEGRAM_API_HASH=abcdef...
   export TELEGRAM_BOT_TOKEN=123456:ABC
   export TELEGRAM_SOURCE_CHAT=@bridge_source
   export TELEGRAM_DESTINATION_CHAT=@bridge_target
   export YANDEX_TRAFFIC_API_KEY=ваш_ключ
   ```
   > Если не задать `TELEGRAM_DESTINATION_CHAT`, бот опубликует карточку в тот же канал, откуда пришло сообщение.

2. **Запустите бота**:
   ```bash
   python -m src.telegram_bot
   ```

3. **Как это работает**:
   - бот слушает сообщения в канале-источнике;
   - при появлении нового сообщения строит карточку;
   - отправляет изображение в целевой канал.

Для остановки нажмите `Ctrl+C` в терминале.

## Кастомизация внешнего вида

- **Фон карточки**: укажите файл через флаг `--background` или переменную `CARD_BACKGROUND`.
- **Шрифты**: Pillow использует `DejaVu Sans`. При необходимости укажите свой шрифт через параметры `--font-regular` и `--font-bold` в `src.generate_card`.
- **Цвета индикаторов**: 0–3 — зелёный, 4–6 — жёлтый, 7–10 — красный. Логику можно изменить в `src/card_generator.py`.

## Частые вопросы

**1. Нужно ли запускать браузер для работы бота?**

Нет, достаточно Python-скриптов. Браузер нужен только, чтобы один раз открыть HTML-помощник и скопировать команды.

**2. Где хранить ключи?**

Рекомендуемый вариант — создать файл `.env` в корне проекта (подробности подскажет `setup_helper.html`) и подключить его через `source .env`.

**3. Можно ли использовать другие источники данных?**

Да. Откройте `src/data_providers/` — вы сможете заменить API или изменить логику получения информации.

**4. Что делать, если бот не отвечает?**

- Проверьте, что все переменные окружения заданы и бот добавлен в канал.
- Убедитесь, что у бота есть права на чтение и публикацию.
- Посмотрите сообщения об ошибках в терминале — они помогут найти причину.
