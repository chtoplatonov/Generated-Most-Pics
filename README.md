# Generated-Most-Pics

Автоматическая генерация карточек с оперативной обстановкой на Крымском мосту.

## Возможности

- парсинг текстов из Telegram-канала, содержащих информацию о трафике на мосту;
- получение актуальной погоды (Open-Meteo) и баллов загруженности (Яндекс.Карты);
- генерация карточки в стиле примера с датой, временем, погодой и баллами по направлениям «в Крым» и «на Кубань»;
- интеграция с Telegram-ботом (Pyrogram) для автоматического приёма сообщений и публикации карточек.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Необходимые переменные окружения для доступа к API:

- `YANDEX_TRAFFIC_API_KEY` — ключ для Яндекс.Карт (Traffic API);
- `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `TELEGRAM_BOT_TOKEN` — данные Telegram-приложения/бота (для Telegram-бота);
- `TELEGRAM_SOURCE_CHAT`, `TELEGRAM_DESTINATION_CHAT` — идентификаторы канала-источника и канала, куда публиковать карточки.

## Генерация карточки из текста

```bash
echo "09:00\n\nСо стороны Тамани очереди перед пунктом ручного досмотра нет." | \
    YANDEX_TRAFFIC_API_KEY=... python -m src.generate_card -o output/card.jpg
```

Файл будет сохранён по указанному пути (формат определяется по расширению).

## Запуск Telegram-бота

```bash
export TELEGRAM_API_ID=...
export TELEGRAM_API_HASH=...
export TELEGRAM_BOT_TOKEN=...
export TELEGRAM_SOURCE_CHAT=@source_channel
export TELEGRAM_DESTINATION_CHAT=@target_channel
export YANDEX_TRAFFIC_API_KEY=...
python -m src.telegram_bot
```

Бот будет слушать канал-источник, генерировать карточки и публиковать их в `TELEGRAM_DESTINATION_CHAT` (если не задан — в тот же канал, откуда получено сообщение).

## Настройка внешнего вида

- Фоновое изображение можно передать ключом `--background` при генерации карточки или переменной окружения `CARD_BACKGROUND` для бота.
- Если фон не указан или недоступен, будет использован градиент по умолчанию.
- Цвета индикаторов автоматически подбираются в зависимости от баллов: 0–3 зелёный, 4–6 жёлтый, 7–10 красный.

## Структура проекта

```
src/
  card_generator.py      # Отрисовка карточки
  data_providers/        # Модули получения погоды и трафика
  generate_card.py       # CLI для генерации карточек
  message_parser.py      # Парсинг сообщений из Telegram
  telegram_bot.py        # Интеграция с Pyrogram
```

## Примечания

- Для корректного отображения текста рекомендуется установить шрифты `DejaVu Sans` (обычно поставляются вместе с Pillow). В противном случае будет использован шрифт по умолчанию.
- При сбоях в API (погода/трафик) скрипт выбросит исключение, чтобы их можно было обработать во внешнем коде.
