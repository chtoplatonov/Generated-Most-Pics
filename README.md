# Generated-Most-Pics

Этот проект помогает автоматически делать понятную картинку об обстановке на Крымском мосту. На изображении видно дату, время, погоду и загруженность в обе стороны. Полученную карточку можно сразу отправить в Telegram.

## Что вы получите
- Telegram-бот, который ждёт новые сообщения о мосте и отвечает карточкой.
- Отдельную команду для ручной генерации карточки из любого текста.
- HTML-страницу-помощник, которая подскажет, какие данные и в каком виде нужно ввести.

## Что нужно подготовить заранее
1. **Компьютер с установленным Python 3.10 или новее.** Скачать можно на [python.org/downloads](https://www.python.org/downloads/).
2. **Telegram-аккаунт** и доступ к [my.telegram.org](https://my.telegram.org), чтобы получить `API ID` и `API Hash`.
3. **Собственный Telegram-бот.** Его создаёт @BotFather и выдаёт `TELEGRAM_BOT_TOKEN`.
4. **Канал-источник** с сообщениями о мосте и (при желании) канал для публикации карточек.
5. **Ключ для Яндекс.Пробок** на [developer.tech.yandex.ru](https://developer.tech.yandex.ru/).
6. **Figma Personal Access Token** и доступ к файлу с макетом карточки. Фон и оформление берутся прямо из Figma, ничего отдельно докладывать не нужно.
   Если точный ID кадра неизвестен, заранее запишите путь до него (например, страница → фрейм) или название фрейма — это пригодится при настройке.

Сохраните эти данные в удобном месте — они понадобятся на следующих шагах.

## Шаг 1. Скачиваем проект
1. Откройте терминал (на Windows подойдёт PowerShell).
2. Скопируйте и вставьте команды:
   ```bash
   git clone https://github.com/your-account/Generated-Most-Pics.git
   cd Generated-Most-Pics
   ```
   Если Git не установлен, скачайте ZIP с кодом с GitHub и распакуйте в любую папку, затем откройте её в терминале.

## Шаг 2. Устанавливаем зависимости
1. Создайте виртуальное окружение — это отдельная папка с нужными библиотеками:
   ```bash
   python -m venv .venv
   ```
2. Активируйте окружение:
   - Windows (PowerShell):
     ```powershell
     .venv\\Scripts\\Activate.ps1
     ```
   - macOS / Linux:
     ```bash
     source .venv/bin/activate
     ```
3. Установите пакеты:
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

## Шаг 3. Заполняем помощник настроек
1. В папке проекта откройте файл [`assets/setup_helper.html`](assets/setup_helper.html). Достаточно двойного клика или «Открыть в браузере».
2. Введите подготовленные значения. Обязательные поля помечены. Отдельный фон вводить не нужно — карточка собирается из Figma по заданному макету.
   Если публикуете в тот же канал, оставьте поле «Канал для публикации» пустым. Поля для ветки и конфигурации слоёв можно не заполнять, если они вам не нужны.
3. Нажмите «Сформировать команды». На странице появится:
   - набор команд `export` для терминала;
   - готовый текст для файла `.env`.
4. Скопируйте команды и вставьте в терминал или сохраните текст в файл `.env` в корне проекта. На Windows переменные можно ввести вручную, следуя подсказке на странице.

## Шаг 4. Запускаем бота
1. Проверьте, что рядом с проектом лежит заполненный файл `.env` **или** вы выполнили команды `export` в текущем терминале. Скрипт автоматически читает `.env`, поэтому достаточно сохранить файл и повторно запустить команду.
2. Выполните команду:
   ```bash
   python -m src.telegram_bot
   ```
3. Бот войдёт в Telegram, будет читать выбранный канал и присылать карточки в указанный чат (и ветку, если вы указали её в помощнике).
   В переменных можно указывать `@username`, прямую ссылку вида `https://t.me/канал` или числовой ID — бот сам добавит `@`, если нужно, и приведёт значение к нужному формату.
   При первом запуске рядом с проектом автоматически появится папка `.telegram_session` — в ней бот хранит ключ авторизации.
4. Чтобы остановить работу, нажмите `Ctrl + C` в терминале. Бот аккуратно завершит соединение и сообщит, что завершает работу.

## Как сделать карточку вручную (не запуская бота)
Иногда нужно быстро получить одну картинку без ожидания сообщения в канале. Есть несколько вариантов:

- **Файл с текстом.**
  ```bash
  python -m src.generate_card -m сообщение.txt -o output/card.png
  ```
  Скрипт ищет файл в текущей папке и в корне проекта. Если в пути есть пробелы, возьмите его в кавычки.

- **Текст прямо в командной строке.**
  ```bash
  python -m src.generate_card -o output/card.png -m "-15:00 Со стороны Тамани очереди нет..."
  ```
  Флаг `-m` можно ставить в любом месте. Программа отличит текст от пути даже если сообщение начинается с дефиса или содержит время.

- **Вставка из терминала.** Укажите `-` вместо имени файла и вставьте текст вручную. Завершите ввод `Ctrl + D` (macOS / Linux) или `Ctrl + Z`, затем Enter (Windows).

Во всех случаях фон и оформление автоматически подтянутся из Figma по уже введённым ключам. Если путь к файлу ошибочный или документ пустой, программа сообщит, какие варианты пути проверялись, и предложит исправить ввод.

### Как указать нужный кадр в Figma

- **Есть node ID.** Введите его в поле `FIGMA_CARD_NODE_ID` — можно скопировать из адресной строки Figma.
- **Знаете только путь.** Укажите цепочку названий через `/` в `FIGMA_CARD_NODE_PATH`, например `Страница/Карточка`. Скрипт пройдёт по дереву и найдёт кадр автоматически.
- **Есть только название.** Заполните `FIGMA_CARD_FRAME_NAME` — будет найден первый фрейм с таким именем.

Можно сочетать варианты. Если указан ID и он валиден, путь и имя не потребуются. Если ID неверный, скрипт попробует путь или название до тех пор, пока не найдёт нужный фрейм. Даже если подсказок не хватило, программа просканирует файл Figma и выберет кадр, где совпадает больше всего нужных слоёв, так что неочевидные названия не остановят генерацию.

### Как настроить слои без переименования

Карточка ожидает несколько текстовых слоёв (дата, время, «Баллы в Крым», «Комментарий на Кубань» и т. д.), иконку погоды и три огня светофора для каждой стороны. По умолчанию скрипт:

- Ищет слои по смыслу: подходят варианты вроде `Карточка/Дата и время/Дата` или `Светофор Крым/Цифра`.
- Если прямого совпадения нет, пытается подобрать ближайший текстовый слой по совпадению слов и подсказывает результат в логе.
- Скрывает и показывает нужную иконку погоды в зависимости от кода Open-Meteo.
- Выбирает цвет светофора исходя из баллов пробки (0–3 зелёный, 4–6 жёлтый, 7–10 красный).
- При необходимости обращается к локальной Ollama, чтобы сопоставить необычные имена.

Если у вас собственные названия или группы, создайте JSON с правилами и укажите его в `.env` (`FIGMA_LAYER_CONFIG=/path/to/layers.json`) или в командной строке (`--figma-layer-config`). Формат один:

```json
{
  "aliases": {
    "Баллы в Крым": ["Карточка/Светофор Крым/Счётчик"],
    "Комментарий на Кубань": ["Карточка/Текстовые блоки/Со стороны Тамани"]
  },
  "weather_icon_layers": {
    "rain": ["Карточка/Погода/Дождливо"],
    "clear": ["Карточка/Погода/Ясно"]
  },
  "traffic_light_layers": {
    "в Крым": {
      "green": ["Карточка/Светофор Крым/Зелёный"],
      "yellow": ["Карточка/Светофор Крым/Жёлтый"],
      "red": ["Карточка/Светофор Крым/Красный"]
    }
  },
  "templates": {
    "Комментарий на Кубань": "{taman_text}\n{weather_description}"
  }
}
```

Любой раздел необязателен: можно задать только псевдонимы или лишь правило для погоды. Значения можно записывать как списком, так и одной строкой. После сохранения файла перезапустите генератор — новые соответствия применятся автоматически.

### Автоматический подбор слоёв через Ollama

Иногда в макете используются необычные названия слоёв, и программа не может их сопоставить с полями карточки. Вы можете подключить локальную нейросеть через [Ollama](https://ollama.com/):

1. Установите Ollama и скачайте любую поддерживаемую модель, например `llama3`.
2. Запустите Ollama (по умолчанию он слушает `http://127.0.0.1:11434`).
3. Добавьте в `.env` строки:
   ```
   OLLAMA_MODEL=llama3
   # OLLAMA_ENDPOINT=http://127.0.0.1:11434  # если используете другой адрес
   ```

При первой попытке заполнить карточку скрипт передаст список нужных полей и названия слоёв в Ollama, получит подходящие пары и переиспользует их дальше. Если Ollama недоступна, работа продолжится как раньше — просто отобразится предупреждение.

> Команда `generate_card` тоже читает значения из `.env`, поэтому достаточно один раз сохранить файл с ключами в корне проекта.

### Откуда берутся погода и пробки

Погода подтягивается из [Open-Meteo](https://open-meteo.com/) по координатам моста, а загруженность — из API Яндекс.Карт. Достаточно сохранить ключ `YANDEX_TRAFFIC_API_KEY` в `.env`: бот и CLI сами обратятся к сервисам. Если ключ отсутствует, не активирован доступ к «Пробкам» или API временно недоступно, в логе появится предупреждение, а баллы для обеих сторон временно будут равны нулю, чтобы карточка всё равно сформировалась.

## Где менять дизайн
Вся графика хранится в Figma. Хотите другой фон, цвета или шрифты? Меняйте макет в Figma — бот подхватит изменения сам. Дополнительные файлы с изображениями не нужны.

## Если что-то пошло не так
- Проверьте, что все обязательные значения введены без лишних пробелов.
- Убедитесь, что бот добавлен в целевой канал и у него есть права на чтение и отправку сообщений.
- Посмотрите сообщения в терминале: при ошибке программа пишет подсказку, что именно не получилось. Если видите подсказку про флаг `-m`, заключите текст сообщения в кавычки или передайте путь к файлу.

На этом всё — наслаждайтесь автоматическими карточками! Если захотите обновить проект, просто скачайте свежую версию с GitHub и повторите шаги установки.
