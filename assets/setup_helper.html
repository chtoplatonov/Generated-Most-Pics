Настройка Crimean Bridge Bot

Заполните форму один раз и нажмите кнопку. Мы сформируем команды для терминала и файл .env, чтобы вы могли запустить бота без ручного ввода значений.

Команды для терминала

Скопируйте команды, вставьте в терминал и нажмите Enter. Для Windows PowerShell замените export на $Env:VARIABLE = \"значение\".

Готовый .env файл

Сохраните текст в файле .env в корне проекта, затем выполните source .env (macOS/Linux) или используйте менеджер переменных в Windows.

Данные не отправляются на сервер. Страница работает локально, поэтому храните ключи в безопасном месте.
