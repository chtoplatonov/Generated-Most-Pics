Готовим окружение для запуска

Настройка Crimean Bridge Bot

Заполните форму один раз — и мы соберём для вас команды терминала и готовый файл .env. Никаких конфликтов блоков: просто введите данные и скопируйте результат.

Данные, которые понадобятся

Зайдите на сайт my.telegram.org, авторизуйтесь по номеру телефона, откройте раздел «API development tools» и скопируйте числовой App ID.
На той же странице my.telegram.org после создания приложения появится App Hash — скопируйте его целиком без пробелов.
Напишите боту @BotFather, создайте или выберите нужного бота и скопируйте токен из ответа (строка вида 123456:ABC-DEF...).
Откройте канал или чат, из которого бот берёт новости, и скопируйте его @username, ссылку t.me/... или числовой ID из раздела «Информация».
Если бот публикует материалы в другом канале, скопируйте его @username или ID. Если публикация не нужна, оставьте поле пустым.
Для форум-каналов Telegram откройте нужную тему, выберите «Скопировать ссылку на тему» и возьмите число после /thread/. Оставьте поле пустым для обычных каналов.
Войдите в свой аккаунт Яндекса, создайте API-ключ в сервисе «Яндекс.Трафик» на странице разработчика и скопируйте полученную строку.
В Figma откройте меню с именем профиля → Settings → Personal access tokens, создайте новый токен и скопируйте его значение.
Откройте макет в Figma и скопируйте часть адреса между /file/ и следующим / — это буквенно-цифровой ключ файла.
Выделите кадр карточки в Figma, нажмите Ctrl/Cmd+L для копирования ссылки и возьмите идентификатор вида 120:456 из конца адреса.
Если макет находится во ветке, в адресе после /branch/ будет её ID. Скопируйте это значение, а для основной ветки оставьте поле пустым.
Укажите путь к JSON-файлу с настройками слоёв, если он используется (например, configs/card.json). Если файл не нужен, оставьте поле пустым.

Готовые результаты

Команды для терминала

Скопируйте команды, вставьте в терминал и нажмите Enter. Для Windows PowerShell замените export на $Env:VARIABLE = "значение".

Готовый .env файл

Сохраните текст в файле .env в корне проекта, затем выполните source .env (macOS/Linux) или используйте менеджер переменных в Windows.

Данные не отправляются на сервер. Страница работает локально, поэтому храните ключи в безопасном месте.
